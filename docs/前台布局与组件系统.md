# 前台布局与组件系统设计

> 覆盖：CMS 博客双栏布局、论坛布局、侧栏 Widget 系统、菜单管理、首页轮播图、用户邀请注册。
> 上游：`docs/模块化架构与产品组合.md`、`docs/公共前台设计冲刺.md`。

---

## 1. 设计原则

1. **后台全控**：侧栏每个卡片的显示/隐藏、排序、标题、内容均在管理面板配置，前台纯渲染；
2. **Widget 即数据**：每个侧栏卡片是 `widgets` 表的一行（`area + type + config JSONB + sort`），新增卡片类型 = 注册新 type 枚举，不改表结构；
3. **菜单即数据**：顶部导航和底部页脚各是一棵 `menus` 记录树，支持父子层级；
4. **轮播图即数据**：`carousels` 表存图片+链接，前台 SSR 渲染 `<img>` + `<a>`;
5. **短代码**：自定义卡片内容中的 `{{user_count}}` 等占位符由后端在输出时替换为实时统计值。

## 2. 数据模型

### widgets（侧栏卡片）

| 列 | 类型 | 说明 |
|---|---|---|
| id | bigserial PK | |
| area | varchar(32) | `blog_sidebar` / `forum_sidebar` / `home_sidebar` |
| widget_type | varchar(64) | 见下方枚举 |
| title | varchar(255) | 卡片标题 |
| config | JSONB | 各类型私有配置（数量、自定义 HTML 等） |
| sort | int | 排序权重 |
| is_active | bool | 是否启用 |
| timestamps | timestamptz | |

**Widget Type 枚举**：

| type | 适用区域 | config 字段 |
|---|---|---|
| author_center | 全部 | `{ show_avatar, show_bio }` |
| categories | blog_sidebar | `{ show_count: true }` |
| tags | blog_sidebar | `{ max_tags: 30 }` |
| latest_articles | blog_sidebar | `{ count: 5 }` |
| hottest_articles | blog_sidebar | `{ count: 5 }` |
| latest_topics | forum_sidebar | `{ count: 5 }` |
| hottest_topics | forum_sidebar | `{ count: 5 }` |
| boards | forum_sidebar | `{}` |
| user_stats | forum_sidebar | `{ show_reg_count, show_online }` |
| custom_html | 全部 | `{ html: "..." }` |
| custom_image | 全部 | `{ image_url, link_url, alt }` |
| custom_text_link | 全部 | `{ text, url }` |

### menus（导航菜单）

| 列 | 类型 | 说明 |
|---|---|---|
| id | bigserial PK | |
| location | varchar(32) | `top_nav` / `footer_nav` |
| label | varchar(128) | 显示文本 |

| sort | int | 排序 |
| parent_id | bigserial NULL | 父菜单项（支持下拉） |
| is_visible | bool | 是否显示 |

### carousels（首页轮播图）

| 列 | 类型 | 说明 |
|---|---|---|
| id | bigserial PK | |
| title | varchar(255) | 管理标识 |
| image_url | varchar(1024) | 图片地址 |
| link_url | varchar(1024) | 点击跳转链接 |

## 3. 用户邀请注册

- settings 新增键：`invite.enabled`(bool)、`invite.max_uses_per_user`(int)
- 已注册用户在个人中心生成邀请码（`invite_codes` 表：code unique, creator_id, max_uses, used_count, expires_at）
- 注册接口接受可选 `?invite=CODE` 参数；有邀请码时可绕过邮箱白名单限制
- 后端校验：邀请码存在、未过期、未超限

## 4. API v1 公开端点

| 端点 | 响应 |
|---|---|
| `GET /api/v1/widgets?area=blog_sidebar` | 按排序返回启用的 widget 列表（含渲染所需数据） |
| `GET /api/v1/menus?location=top_nav` | 菜单树 |
| `GET /api/v1/carousels` | 启用的轮播图列表 |
| `POST /api/v1/register` | 用户注册（含邀请码校验） |
