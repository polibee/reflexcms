# 积分与邀请系统设计

## 积分获取途径（后台 settings 可配置数量）

| 途径 | 设置键 | 默认值 |
|---|---|---|
| 发布文章 | points.earn_article | 10 |
| 发帖 | points.earn_topic | 5 |
| 回复帖子 | points.earn_reply | 2 |
| 评论文章 | points.earn_comment | 3 |
| 每日签到 | points.earn_signin | 1 |
| 邀请新用户 | points.earn_invite | 20 |

## 积分消费

| 用途 | 设置键 | 默认值 |
|---|---|---|
| 生成邀请码 | points.cost_invite_code | 50 |

## 表结构

**user_points**: user_id PK, balance int, total_earned int, updated_at

**point_transactions**: id, user_id idx, amount(int,正=获得/负=消费), reason varchar(64), created_at

**invite_codes**: 已有（增加 creator_id 校验 + points 门槛扣减）

## 流程

生成邀请码：
1. 管理员（super-admin）→ 无限生成，不扣积分
2. 普通用户 → 检查余额 >= cost → 扣减 → 生成
3. 余额不足 → 422 "积分不足"

积分发放：
- 文章发布 → ArticlePublished 事件监听
- 帖子创建 → ReplyToTopic / topic create 后同步发放
- 评论审核通过 → CommentModerated(approved) 后发放
- 每日签到 → POST /api/v1/signin 接口，每天一次
