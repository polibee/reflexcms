下面按你的目标设计：

> **Goravel + Nuxt.js 开发一个个人/社区型 CMS + BBS 平台 MVP**
>
> 定位：类似 **WordPress + Flarum + Ghost** 的轻量版本
> 初期不做插件系统，重点做好核心架构，为未来 AI 功能预留接口。

---

# Goravel + Nuxt.js CMS+BBS MVP 开发文档

## 1. 项目定位

### 产品目标

打造一个：

* 内容管理系统（CMS）
* 博客系统
* BBS社区
* 多作者发布平台
* AI增强内容平台

未来扩展：

* AI写作助手
* AI文章总结
* AI搜索
* AI审核
* AI知识库

# 最终推荐技术组合

```
Frontend

Nuxt 4
+
Tailwind
+
TypeScript


Backend

Goravel


Database

PostgreSQL


Cache

Redis


Search

Meilisearch


Storage

S3兼容对象存储


AI

独立AI Service
```

这个架构不会限制未来发展，也不会像一开始做插件系统那样增加复杂度。对于“个人博客 → BBS → AI社区”的路线，MVP阶段比较合适。
